# 🏡 WonderLust - Airbnb Clone

WonderLust is a full-stack web application inspired by Airbnb that allows users to browse, create, edit, review, and manage property listings. The project follows the **MVC (Model-View-Controller)** architecture and provides a secure, responsive, and user-friendly experience.

---

## 🚀 Features

- 🔐 User Authentication & Authorization
- 🏠 Create, Edit, Delete, and View Property Listings
- 📷 Image Upload using Cloudinary
- ⭐ Add and Manage Reviews
- 📍 Location and Property Details
- 📱 Responsive User Interface
- 🔍 Search and Browse Listings
- 🛡️ Protected Routes with Passport.js
- ⚠️ Error Handling & Flash Messages

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/wonderlust.git
```

### Navigate to the Project

```bash
cd wonderlust
```

### Install Dependencies

```bash
npm install
```

### Create Environment Variables

Create a `.env` file in the project root and add:

```env
ATLASDB_URL=your_mongodb_connection_string

CLOUD_NAME=your_cloudinary_cloud_name
CLOUD_API_KEY=your_cloudinary_api_key
CLOUD_API_SECRET=your_cloudinary_api_secret

SECRET=your_session_secret
```

### Start the Server

```bash
node app.js
```

or

```bash
npm start
```

Visit:

```
http://localhost:8080
```

## 📖 MVC Architecture

The project follows the **Model-View-Controller (MVC)** design pattern.

- **Models** → Handle database operations.
- **Views** → Render UI using EJS templates.
- **Controllers** → Process requests and business logic.
- **Routes** → Define application endpoints.
